Ingest & Normalize
Validate header & reference build. Left-align indels, split multiallelics, decompose. Stream records — never load the whole VCF into RAM.

02
QC & Hard Filters
Keep FILTER=PASS. Enforce depth (DP), genotype quality (GQ), allele balance. Mask low-complexity / known-artifact regions.
bcftools viewregion BED mask
03
Columnar Store
Write normalized variants to Parquet, partitioned by chromosome. Vectorized scans + predicate push-down instead of re-parsing text.
pyarrowParquet / chrom
04
Index
bgzip + tabix for region queries. Lightweight gene→variant and rsID→variant maps for O(1) agent lookups.
tabixgene / rsID index
05
Annotate (join)
Join population AF, clinical significance, in-silico scores and phenotype panels. Cached locally (existing data/cache pattern).
gnomADClinVarCADDHPO panels

Rarity (gnomAD AF), consequence severity, phenotype match, inheritance model (de novo / recessive / comp-het). Emits a ranked, provenance-logged candidate set.

Heavy, deterministic variant reduction belongs in cheap, auditable data engineering — not in expensive, non-reproducible LLM reasoning. The agents stay lean and trustworthy because the data layer hands them a small, well-provenanced, reproducible candidate set. This is reproducibility the research-tool framing requires: the filtering is logged and re-runnable, not a black box.
